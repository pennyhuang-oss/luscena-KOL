## 怎麼看這份審閱包

1. 先看下面的**十角色總覽表**：每個角色一列，看第一眼喜不喜歡。
2. 喜歡或想改的角色，打開 `Lxx.md`。每份檔案的章節順序都一樣：一眼看懂 → 基本設定 → 個性 → 說話方式與三則貼文 → 外型方向 → 場景 → 四張形象照 → 三條故事 → 區隔 → 需要 Penny 選擇的事項 → 限制註記 → 相對 v0 的修改。
3. 到 `PENNY_CHOICES.md` 勾選：每個角色「喜歡／要改／換掉」，以及需要你決定的選項。
4. 選定之後，把 `PRODUCER_REFERENCE_NEEDS.md` 交給 AIGC 製作師評估人物形象。製作師會依那份清單請你提供或確認 OK／NG 參考圖。
