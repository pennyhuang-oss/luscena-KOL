## 2. 流程規則（製作師定的）

- **能裁局部就裁局部改**：Nano Banana 每次編修都會重畫整張，連續整張改十幾次背景會糊、出現色塊（追加 168）。只有光線這類非整張不可的才整張改。

- 每次預設只跑 **1 張**；結果不能用才補跑。
- **先確認構圖／姿勢，再修細節**（胸口、胸罩、臉、汗……）。姿勢沒對之前不修細節。
- 每輪改完只把改的區域貼回，保留已確認的部分（例如 Vicky 第三張皮膚以 v7 為準）。
- 反覆修不好、而網頁版工具（Color Grading、Relight、Enhancer、Angles、Layer Decomposition）可能解決時，主動提出。

## 3. 已知的坑

- **真人參考照的臉會外洩**：Seedream 吃真人參考照，常把照片裡那個人的臉、眼睛顏色、指甲、戒指、泳衣顏色一起抄過來，即使有 Element（Vicky 第四張 追加 135、v3）。
- **拿真人參考照當底圖換人**：Nano Banana Pro 會判 NSFW（Vicky 第四張，退點）。
- **Kanon 的臉偏幼**：Seedream＋Kanon Element 遇到稍性感的構圖就 NSFW；Nano Banana Pro＋Element 較能過（追加 127）。
- **明顯透視（濕布透膚）**：Nano Banana 2.1 只給很淡的效果，Pro 直接 NSFW；本機合成不自然（追加 126）。
- **胸部加大＋露內衣同時要求** → 易被擋；拆開做。
- 平台預設輸出比例可能自動換（Nano Banana Pro 的 `auto` 曾變 3:4），要指定比例。
- GPT Image 系列遇擦邊內容幾乎都擋。
- 要「完全照真人參考照的姿勢」：Seedream 抄不準；改兩步法——參考照**先本機裁成輸出比例**，Nano Banana 2.1 只改衣服髮型背景，再裁頭部用 Nano Banana Pro 換角色臉（追加 182）。比例不合時 2.1 會重構圖、姿勢跑掉。
- 大幅改腿（例如兩腿都離地）時 Nano Banana Pro 容易多畫一條腿；prompt 明寫「exactly TWO legs」並逐條指定每條腿（Leg 1／Leg 2 的位置）可修正（追加 174）。
- 鼠蹊／胯下部位的小細節（縫線等），prompt 寫出 groin／crotch 會被 Nano Banana 2.1 擋；改本機畫線＋羽化（追加 166）。
- Seedream 拿既有圖當參考、文字要求改場景結構（水深、扶梯形狀）→ 會整張重畫、構圖跑掉；改道具形狀用 Nano Banana Pro（2.1 只改得動顏色類，例如水變深藍）（追加 151）。

## 4. 待驗證

- 「角色本人圖當底圖＋參考圖只當姿勢」用 Nano Banana Pro 重擺姿勢（Vicky 第四張，追加 136）：**臉保住了**（是 Vicky），手勢大致對，但鏡頭距離、水位、手的角度沒照到 → 適合「保臉」，不適合「姿勢一模一樣」。
- Seedream 只放 1 張真人參考照＋Element（追加 136 v3）：構圖比多張參考近，但臉、指甲、戒指仍外洩，手臂角度也不同。
- 結論（暫定）：要「姿勢一模一樣又保臉」目前沒有一步到位的方法；可行組合是「Nano Banana Pro 保臉重擺 → 本機裁切對齊構圖 → Nano Banana 2.1 局部修水位／手」。

## 5. 為什麼「照參考圖擺姿勢」常常不準（2026-10-15 分析）

1. 手上的模型都不是姿勢控制工具（沒有 ControlNet／OpenPose）；參考圖只會被「大概抄」：場景、氛圍、大動作，細節（頭偏多少、指尖方向、鏡頭距離）不在它抄的範圍。
2. 「抄姿勢」和「保角色的臉」互相拉扯：越照真人參考照，越會連那個人的臉、眼睛顏色、指甲、飾品一起抄；越保角色臉，姿勢就回到模型自己的預設。
3. 模型有強烈的預設畫面（例：泳池自拍＝人在正中、正面、腰部以上出水、手放頭頂）；參考圖越偏離預設（偏心、歪頭、超近廣角、手擋臉）越難照抄，模型尤其會避免手擋住臉。
4. 文字描述姿勢很粗，左右常搞混（Wendy 第三張左右手相反）。
5. 用角色圖當底圖重擺時，Nano Banana 會死守底圖的構圖（距離、水位）。
- 對策：把姿勢拆成本機可控的部分（裁切、移位決定構圖）＋模型做得到的局部修改（水位、單一手部用「手繪再轉照片」）；或換一張比較符合模型預設、或**看不到臉的背面參考圖**（不會臉外洩，Vicky 第四張水中照 追加 137）。
- 兩步法（先在參考圖上改姿勢／衣服，再換成角色）第一步有效：背面參考照改成回頭看鏡頭，腿腳構圖完全保留（追加 138）。但要再加大軀幹扭轉角度時，模型在腿腳固定下不肯動（追加 139～140），第一次改到的角度就接近極限。
- 大幅扭轉軀幹（追加 141）：Kling O1 最敢改且保住腳的位置（0.5 點，但畫質較低）；Seedream 會整張重畫；FLUX 3 這類暴露度直接 NSFW；Nano Banana Pro 只做小角度。
