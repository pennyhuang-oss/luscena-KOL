## H. Prompt 使用方式、需要附的參考圖、已知限制

**使用順序**
1. **階段 1 凜本人的臉部候選**：G-2 的臉部候選，純文字（全身照 B 等臉選定之後才做）。數量依 `persona_pack_v1/PRODUCER_REFERENCE_NEEDS.md` §6.2 的低／中方案假設（每角色 4 或 8 張）。不附任何真人照片，也不用角色造型建角。
2. **Penny／客戶挑選**：挑出的那張成為「身分參考圖 A」（凜本人）。在挑選之前，任何候選都不算凜。
3. **階段 2 身分測試**：G-3 的 T1–T3（低方案）或 T1–T8（中方案），只附參考圖 A。全身中性照 B 也在這一步附 A 產生（新增項目，計費見 `REFERENCE_AND_ACCEPTANCE.md` §7）。製作師如果在階段 1 先出不附參考圖的全身圖，那只是「獨立體態候選」，不代表和臉部候選是同一人，不能直接當成 B；請回報做法。
4. **造型漂移檢查**：G-3 的 W1（必做；屬於 L02 身分建立「本人＋Vera 的臉」，見 `persona_pack_v1/PRODUCER_REFERENCE_NEEDS.md` §6.4 第 3 項），W2、W3 建議做（新增項目，計費見 `REFERENCE_AND_ACCEPTANCE.md` §7）。通過後，W1 那張成為「Vera 造型確認圖 V」，給 Penny 看「本人＋Vera 的臉」。
5. **形象照**：G-4，每一張都附參考圖 A。服裝、假髮或光線另有授權參考時可以一起附，但那張圖**不能有人臉**。

**參考圖的用途分工**
| 參考圖 | 用途 | 注意 |
|---|---|---|
| A：選定的凜本人中性候選照（無假髮、無彩片、低妝） | 身分（臉與五官） | 每一套角色造型都附這張；不要為了某個角色另生一張臉；不要和其他人的臉混在同一次生成 |
| 身分測試通過的 T2／T3 | 補充身分參考（同一人不同角度） | 只有在 A 已鎖定之後才加入 |
| V：造型漂移檢查通過的 Vera 版（W1） | 只在 Vera 的造型照當補充 | 不拿來做其他角色（會把銀白假髮與 Vera 的妝帶到別的角色）；不取代 A |
| 角色服、假髮、妝容、光線參考 | 風格 | 先裁掉人臉，或改用文字描述。**不要假設模型會只學服裝或髮型而忽略圖中的五官**。不用真實 Coser 的照片當臉部參考；同人 IP 造型在 C-L02-2 選 B 且權利確認完成前，不放進生成輸入 |

**目前沒有任何參考圖**：OK／NG 參考都還是待補（見 `REFERENCE_AND_ACCEPTANCE.md`）。本頁沒有附圖，也沒有做過撞臉測試或造型漂移測試。

**已知限制**
- 文字 prompt 無法保證每次都是同一張臉；鎖定之後要靠參考圖或角色模型維持，並且逐張人工檢查。
- **假髮、彩片、舞台妝是最主要的漂移來源**：模型常把「新髮色＋新瞳色＋新妝」當成另一個人，臉型、眼形、唇形跟著改。人設的要求是換假髮不能讓人認不出是同一個人；每一位新角色都要重新做身分確認。
- 淚痣很小，常被省略、畫錯邊、被舞台妝蓋掉或被眼鏡框擋住；鏡像時會換邊，要確認是否為鏡像。
- 模型容易把性感造型的臉往「年輕、動漫感、預設美女」收斂，接近 L03 或 L10；要對照 B 節逐項看心形臉、下顎角、M 型唇峰、淚痣是否還在。
- 部分工具會拒絕、模糊或改寫兔女郎、泳裝、緊身戰鬥服這類造型；不要用改字或繞過的方法硬做，照實回報被擋的情況與工具條款。
- 角色場景的招牌、牌面與文字不靠生成；需要文字時由排版另外處理。
- 部分模型的長寬比選項不同（例如沒有 4:5），可以用 3:4 出圖再裁切，回報時寫明。
- 公開時怎麼揭露 AI，由團隊依實際操作另外決定（尚未決定），不在本頁處理。

## I. 製作師可以自由替換的方法與需要回報的取捨
