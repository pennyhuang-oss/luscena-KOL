## H. Prompt 使用方式、需要附的參考圖、已知限制

**使用順序**
1. **階段 1 臉部候選**：G-2 的臉部候選，純文字（全身照 B 等臉選定之後才做）。數量依 `persona_pack_v1/PRODUCER_REFERENCE_NEEDS.md` §6.2 的低／中方案假設（每角色 4 或 8 張）。不附任何真人照片。
2. **Penny／客戶挑選**：挑出的那張成為「身分參考圖 A」。在挑選之前，任何候選都不算翔哥。
3. **階段 2 身分測試**：G-3，只附參考圖 A；低方案做 T1–T3（3 張），中方案做 T1–T8（8 張）。全身中性照 B（G-2，附參考圖 A）與造型變化檢查等是新增項目，在 A 選定之後做，計費見 `REFERENCE_AND_ACCEPTANCE.md` §7。
4. **形象照**：G-4，附參考圖 A；如果另有授權的場景或風格參考，可以一起附，但那張圖**不能有人臉**。

**參考圖的用途分工**
| 參考圖 | 用途 | 注意 |
|---|---|---|
| A：選定的中性候選照 | 身分（臉與五官） | 只用同一個人的圖；不要和其他人的臉混在同一次生成 |
| 身分測試通過的 T2／T3 | 補充身分參考（同一人不同角度） | 只有在 A 已鎖定之後才加入 |
| 全身中性照（選定後） | 補充體態參考（身高感、壯、肚子） | 只有在 C-L06-3 選定、而且 Penny 看過全身照之後才加入 |
| 刺青圖樣（待原創定稿） | 只用於刺青圖案 | 純圖樣、不含人；位置用文字寫「本人右前臂外側」，不靠圖樣圖決定左右 |
| 膚色色票（和 L09 分開，待補） | 比對膚色 | 純色塊，主要用來人工比對；要不要放進生成輸入由製作師判斷並回報 |
| 服裝、場景、光線參考 | 風格 | 先裁掉人臉，或改用文字描述。**不要假設模型會只學服裝或光線而忽略圖中的五官** |

**目前沒有任何參考圖**：OK／NG 參考都還是待補（見 `REFERENCE_AND_ACCEPTANCE.md`）。本頁沒有附圖，也沒有做過撞臉測試；刺青圖樣與膚色色票也還沒有。

**已知限制**
- 文字 prompt 無法保證每次都是同一張臉；鎖定之後要靠參考圖或角色模型維持，並且逐張人工檢查。
- 刺青常被模型省略、畫錯手臂或畫到前臂內側；鏡像時會換邊，要確認是否為鏡像。圖樣還沒定稿，細節不一致不算失敗，但位置（本人右前臂外側）必須對。
- 模型畫「成熟、粗獷的男人」時很容易自己加鬍子或鬍渣；這會讓他靠近 L09、L05。每張都要確認是刮乾淨的。
- 「壯」容易被做成健身房的健美身材；「小肚子」容易被做成微胖（靠近 L05）。要對照 B 節看肩寬、胸背厚、手臂粗是否還在。
- 曬黑常被修成均勻的淺膚，或變成油亮；T 恤曬痕常被省略。要和 L09 的色票並排看。
- 機油痕只在手上；不要變成臉上的髒污。
- 生成圖裡的手機、電腦螢幕一律模糊或抽象，不出現遊戲畫面；真實遊戲截圖另外交付，不合成進人物圖。
- 機車、工具、遊戲的真實商標都不能出現；店名不寫。招牌、圖上文字不靠生成，需要文字時由排版另外處理。
- 部分模型的長寬比選項不同（例如沒有 4:5），可以用 3:4 出圖再裁切，回報時寫明。

## I. 製作師可以自由替換的方法與需要回報的取捨

- 可以改用自己的流程，例如：用角色產生器先出角色表、用單張參考圖建立可重複使用的角色元素、或在臉鎖定後訓練專屬角色模型（需要幾張圖、用哪個工具、帳號能不能訓練，都依製作師實際帳號確認；官方來源的張數互相衝突，輸出能不能拿來訓練也有適用疑義，見 `MODEL_AND_WORKFLOW_OPTIONS.md` §2.3、§2.5）。各選項的說明與查證狀態見 `MODEL_AND_WORKFLOW_OPTIONS.md`。
- 改寫 prompt 時，請保留 B、C 節的「必須維持」項目，並回報：
  1. 實際使用的工具、模型名稱與版本、prompt 全文、參考圖編號與來源；
  2. 每一步的張數與花費（實際數字；不要估算後當成實際值）；
  3. 失敗樣本與原因（保留，不只交最好的一張）；
  4. 為了維持身分犧牲了什麼（例如換裝自由度、表情幅度、體態準確度、刺青細節）；
  5. 和 L05、L09 並排比對的結果（L09 要含遮掉鬍子的版本）。
- 任何需要付費、訓練或大量生成的步驟，要先取得 Penny 的授權與費用上限。
