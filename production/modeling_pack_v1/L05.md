## H. Prompt 使用方式、需要附的參考圖、已知限制

**使用順序：寫實身分**
1. **階段 1 臉部候選**：G-2 的臉部候選，純文字（全身照 B 等臉選定之後才做）。數量依 `persona_pack_v1/PRODUCER_REFERENCE_NEEDS.md` §6.2 的低／中方案假設（每角色 4 或 8 張）。不附任何真人照片。每一輪做成年外觀檢查。
2. **選定身分參考圖 A**（製作師挑選，或依製作師的流程交客戶選定；A 由製作師建立與管理）：選出的那張成為「身分參考圖 A」。在挑選之前，任何候選都不算阿凱。
3. **階段 2 身分測試**：G-3，只附參考圖 A；低方案做 T1–T3（3 張），中方案做 T1–T8（8 張）。全身中性照 B（G-2，附參考圖 A）與造型變化檢查等是新增項目，在 A 選定之後做，計費見 `REFERENCE_AND_ACCEPTANCE.md` §7。
4. **形象照**：G-4，附參考圖 A；如果另有授權的場景或風格參考，可以一起附，但那張圖**不能有人臉**。

**使用順序：Q 版設計稿（C-L05-1 選定前，按執行者建議 A 估）**
5. 參考圖 A 選定之後，才開始 G-5-2 的 Q 版臉候選；先決定 G-5 開頭的三種做法用哪一種。
6. **選定 Q 版正面定稿**（製作師選定，或依其流程交客戶選定），成為「Q 版參考圖 Q」，由製作師建立與管理。
7. G-5-3 的表情與背面，只附 Q。

**參考圖的用途分工**
| 參考圖 | 用途 | 注意 |
|---|---|---|
| A：選定的寫實中性候選照 | 寫實身分（臉與五官） | 只用同一個人的圖；不要和其他人的臉混在同一次生成 |
| 身分測試通過的 T2／T3 | 補充寫實身分參考（同一人不同角度） | 只有在 A 已鎖定之後才加入 |
| 服裝、倉庫、光線參考 | 寫實風格 | 先裁掉人臉，或改用文字描述。**不要假設模型會只學服裝或光線而忽略圖中的五官**；不能有真實物流、電商商標 |
| A 用在 Q 版候選（可選） | 只當 Q 版的臉型與五官位置參考 | 可能把 Q 版拉向寫實或 3D；用了要回報，並逐張檢查畫風 |
| Q：選定的 Q 版正面定稿 | Q 版的身分與畫風 | Q 版表情、背面只附這張 |
| Q 版畫風參考（如果有） | 畫風 | 必須是授權或自有的圖；不能是現有 IP 角色、吉祥物或貼圖。若圖中有角色臉，**不要假設模型只學畫風而不學那張臉** |

**驗收分開**
- **寫實身分**：照 `REFERENCE_AND_ACCEPTANCE.md` §4.1，加上 C 節的成年外觀檢查與 L06 並排比對。
- **Q 版設計稿**（另外驗收；由製作師判斷，或依其流程交客戶選定）：
  1. 連續性：把 Q 版和參考圖 A 並排，逐項對照 C 節「必須維持：Q 版」的清單；對不上的項目要修。
  2. 認得出：請非執行者看寫實照與 Q 版，說出哪些特徵對得上。
  3. 左右：耳釘在他本人的左耳（正面朝讀者時在畫面右側）；短線眼沒有被畫成雙眼皮。
  4. 原創：不像任何現有的動漫角色、吉祥物或貼圖角色。
  5. 成年角色：沒有制服、書包、教室等校園元素。
- 寫實過關不等於 Q 版過關；Q 版過關也不代表寫實身分可以跳過身分測試。

**目前沒有任何參考圖**：OK／NG 參考都還是待補（見 `REFERENCE_AND_ACCEPTANCE.md`）。本頁沒有附圖，也沒有做過撞臉測試；Q 版也還沒有任何草稿。

**已知限制**
- 文字 prompt 無法保證每次都是同一張臉；鎖定之後要靠參考圖或角色模型維持，並且逐張人工檢查。
- 圓臉＋微胖＋24 歲很容易被工具畫成學生；鬍渣、黑眼圈、毛孔也常被「修乾淨」。每一輪都要做人工估齡。
- 單眼皮常在笑或 3/4 角度時被畫出雙眼皮摺痕；淡鬍渣常被省略或畫成鬍子造型；耳釘常畫錯耳或在鏡像時換邊。
- 寫實的「微胖」容易被做成「壯」，接近 L06；要看肩寬中等、手臂有肉、肚子微凸、沒有厚實胸背。
- Q 版的小特徵（鬍渣點、耳釘小點、眉尾 3 筆）最容易在表情變化時消失；每張都要對照 C 節清單。
- 附寫實照片做 Q 版，可能讓畫風變寫實或 3D；不附，連續性只能靠文字與人工對照。
- 紙箱、背心、招牌不出現真實公司、電商或物流商標；圖上的中文字一律後製排版。
- 部分模型的長寬比選項不同（例如沒有 4:5），可以用 3:4 出圖再裁切，回報時寫明。

## I. 製作師可以自由替換的方法與需要回報的取捨

- 可以改用自己的流程，例如：用角色產生器先出寫實角色表、用單張參考圖建立可重複使用的角色元素、或在臉鎖定後訓練專屬角色模型（需要幾張圖、用哪個工具、帳號能不能訓練，都依製作師實際帳號確認；官方來源的張數互相衝突，輸出能不能拿來訓練也有適用疑義，見 `MODEL_AND_WORKFLOW_OPTIONS.md` §2.3、§2.5）。Q 版可以用插畫工具或由人繪製。各選項的說明與查證狀態見 `MODEL_AND_WORKFLOW_OPTIONS.md`（Q 版能不能從寫實角色延伸，該文件也列為需製作師測試）。
- 改寫 prompt 時，請保留 B、C 節的「必須維持」項目（寫實與 Q 版兩份清單，含成年外觀），並回報：
  1. 實際使用的工具、模型名稱與版本、prompt 全文、參考圖編號與來源；寫實與 Q 版分開列；
  2. 每一步的張數與花費（實際數字；不要估算後當成實際值）；寫實與 Q 版分開列，透明背景 PNG、反光背心版本（C-L05-4 選 B 時）也分開列（`persona_pack_v1/PRODUCER_REFERENCE_NEEDS.md` §6.4 第 6 項）；
  3. 失敗樣本與原因（保留，不只交最好的一張），包括被估得太年輕的樣本、冒出雙眼皮的樣本、Q 版被拉成寫實的樣本；
  4. 為了維持身分犧牲了什麼（例如換裝自由度、表情幅度、體態準確度）；**Q 版用了 G-5 開頭的哪一種做法、有沒有附寫實參考圖 A，以及因此得到和失去了什麼**（連續性 vs 畫風）；
  5. 和 L06 並排比對的結果（含年齡差），以及和 L07 的比對；Q 版和寫實參考圖 A 的並排對照。
- 生成、訓練、付費與額度，由製作師依自己的帳號權限和與客戶的約定處理，不需要 Penny 批准；回報時寫明實際張數與花費（以帳戶實際扣除為準）。Q 版設計稿的份量依 C-L05-1，由製作師和客戶依其流程確認（`REFERENCE_AND_ACCEPTANCE.md` §6）。
