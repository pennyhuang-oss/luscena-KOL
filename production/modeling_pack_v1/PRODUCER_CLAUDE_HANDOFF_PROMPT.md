# 給製作師的 Claude 交接 prompt

> 用法：製作師把下面整段 prompt 貼給自己的 Claude（例如連接了 Higgsfield MCP 的 Claude）。點程式碼區塊右上角的複製鈕即可一次複製。
> **責任分工（2026-10-07 Penny 指示）**：Penny 只負責初步人設建立與交付。製作師接手後，自行決定工具、模型、生成、訓練、參考圖、製作方法與迭代流程；建模成果由製作師判斷是否可用，或依製作師的工作流程交客戶選定、驗收與定案；費用、額度與製作範圍由製作師依帳號權限與客戶約定處理。不需要 Penny 批准生成、訓練、選臉、鎖定身分或核准形象。
> 這一版取代較早版本的交接 prompt：較早版本中「只做詢價」「取得 Penny 授權與費用上限前不得生成或訓練」「由 Penny／客戶選臉後才繼續」「每批停下等 Penny 與主管」等要求已取消。紀錄見 `review/RESPONSIBILITY_CHANGE_TASK_002_2026-10-07.md`。
> **交付版本**：分支 `claude/luscena-kol-initial-draft-et17t8`，責任分工調整的內容 commit `ef096d8074eace9b297fb7c2241092a0fbaead73`（SHA 在內容 commit 之後的下一個 commit 補上）。

【怎麼開始】
1. 讀完必讀檔案、做完版本與檔案檢查後，向製作師用一頁說明：你理解的任務與各角色重點、建議的流程（含替代方案與取捨）、第一批建議範圍與預計張數、需要製作師決定的事（例如工具、模型、費用）、需要客戶確認的待選項目。之後依製作師的指示直接開始建模，不需要等 Penny。
2. 工具與費用：確認製作師帳號實際可用的功能與模型、每一步的扣點或費用（能用報價或查價功能就先查），把查到的數字告訴製作師；查不到就說查不到，不要用估算值冒充實際值。花費與額度依製作師的指示處理。
3. 參考素材：照 REFERENCE_AND_ACCEPTANCE.md §2 登記來源與權利狀態；權利不明的圖不放進生成或訓練。repo 裡目前沒有任何參考圖。
4. 建議（不強制）分批：先做撞臉優先 1 的配對（L02↔L10、L01↔L08、L05↔L06），每個角色少量候選，並排比較；不要一次把十張臉當成定案。
5. 身分參考圖 A（臉）與全身參考圖 B 由製作師選定、建立與管理；需要客戶選時，依製作師的流程交客戶選。選定之後再做身分測試與形象照，並記錄是哪一張、由誰在哪一天選定。

【製作要求（請保留）】
- 原創、成年：十個角色都是原創虛構的成年人。不仿製真人、名人、既有 KOL、既有動漫或遊戲角色的臉；不用真人名字描述長相；不做幼態、學生制服或校園場景；不越過各角色人設檔 §10 的限制。
- 身分一致性：保留各建模頁 B、C 節「必須維持」的身分特徵；左右以角色本人為準，注意鏡像。文字 prompt 不能保證每次是同一張臉；選定參考圖之後要附參考圖或用角色模型維持身分，並逐張人工檢查。
- 十人區隔：撞臉配對要並排比較；區分要靠骨架與五官，不只靠髮型、髮色、眼鏡、鬍子或服裝。
- 工具限制與條款：遵守工具的使用條款與 NSFW、版權／IP 限制。用生成圖訓練角色模型前，先確認條款與許可（MODEL_AND_WORKFLOW_OPTIONS.md §2.5 的適用疑義）。
- 素材權利：參考圖登記來源、權利與用途限制；權利不明的不放進生成或訓練。
- 失敗樣本：保留失敗樣本與原因，不只交最好的一張；修正後重新測試。
- 紀錄：每一批記錄工具、模型名稱與版本、prompt 全文、參考圖編號與來源、生成與交付張數、實際花費（以帳戶實際扣除為準）。
