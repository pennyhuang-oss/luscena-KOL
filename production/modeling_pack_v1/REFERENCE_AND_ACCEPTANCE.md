## 2. 參考素材登記表

每一張參考圖都要登記，沒有登記的圖不能放進生成或訓練。

| 欄位 | 說明 |
|---|---|
| 參考編號 | 例：REF-L01-HAIR-OK-01 |
| 角色與類型 | 角色 ID；臉／髮型／體態／服裝／光線／構圖／場景 |
| OK 或 NG | OK＝要往這個方向；NG＝要避開 |
| 原始來源 | 檔案出處或連結；自己拍的寫拍攝人與日期 |
| 權利狀態 | 自拍或自有／授權圖庫（附授權編號）／客戶提供並附授權說明／合成候選（本專案生成）／權利不明 |
| 用途限制 | 授權條款寫的限制，例如只限內部參考、不可商用、不可修改 |
| 可否放進生成輸入 | 可／不可。權利不明的一律不可 |
| 可否用於訓練 | 可／不可。必須授權條款明確允許，且圖中只有本專案的原創人物 |
| 確認人與日期 | 誰確認了權利狀態 |

**臉部參考的特別規則**
- 臉部預設是**原創身分**。真人照片只能當「方向」討論（例如臉型類型、五官比例），不放進生成輸入，也不用來訓練。
- 不用藝人、網紅或任何真實人物的名字描述長相；不要求仿製真人或既有 KOL 的臉。
- 「合成候選」只有在 Penny／客戶選定之後，才能當身分參考圖。
- 髮型、服裝、光線的參考圖如果有人臉，先裁掉人臉再用，或改用文字描述。不要假設模型會只學髮型而忽略圖中的五官。

## 3. 身分測試和公開形象照分開

| | 身分測試 | 公開形象照 |
|---|---|---|
| 目的 | 確認是同一個人、和其他九人分得開 | 帳號頭像與代表照 |
| 規格 | 中性均勻光、中灰或白背景、露出額頭與眉毛、無妝或淡妝、表情中性；角度與表情依 `PRODUCER_REFERENCE_NEEDS.md` §6.2 的 T1–T8 | 依各角色建模頁 F 節的服裝、場景、光線、鏡位、表情 |
| 會公開嗎 | 不公開 | 選定後才可能公開；公開前仍要依當時決定的 AI 揭露方式與平台規定處理 |
| 誰看 | 製作師、Penny、客戶、主管 | Penny、客戶 |

形象照好看，不代表身分測試通過；身分測試必須先過。

## 4. 審查候選人物

### 4.1 審查項目

| # | 項目 | 怎麼看 | 只看文字能判斷？ |
|---|---|---|---|
| 1 | 角色相符 | 臉型、五官、膚色、年齡感是否符合建模頁 B 節；有沒有偏向「預設美女臉」或太年輕 | 規格本身可以用文字核對；**是否符合要看圖** |
| 2 | 十人區隔 | 和撞臉配對並排比較（`persona_pack_v1/00_OVERVIEW.md` 的優先 1、2、3 配對）；把頭髮、眼鏡、鬍子遮掉後仍分得開 | 不能；必須看圖 |
| 3 | 角度與表情維持身分 | T1–T8 同一人；痣、酒窩、耳釘、刺青等在正確的一側（角色本人的左右；注意鏡像） | 不能；必須看圖 |
| 4 | 造型變化維持身分 | 換髮型、換妝、換服裝（L02 換假髮與舞台妝）後仍是同一張臉 | 不能；必須看圖 |
| 5 | 臉與體態一致 | 全身照的身高感、肩寬、體型和規格一致；同一角色不同照片的體型一致 | 不能；必須看圖 |
| 6 | 成年外觀 | 一看就是成年人；沒有幼態比例、學生制服或校園場景 | 規格可以用文字核對；成像要看圖 |
| 7 | 基本解剖與手部 | 手指數量、關節、四肢比例、牙齒、耳朵、眼睛對稱程度自然 | 不能；必須看圖 |
| 8 | 文字與商標 | 畫面沒有可讀的假文字、真實商標、真實店名 | 不能；必須看圖 |
| 9 | 尺度與條件項 | 只做目前允許的尺度 1；沒有越過各角色 §10 的限制 | 規格可以用文字核對；成像要看圖 |

### 4.2 判讀規則
- 不使用沒有校準過的數值門檻。臉部相似度之類的自動分數可以當參考，但**自動量測的結果不等於通過**，最後由人看圖判斷，並寫下理由。
- 痣、耳環、刺青、戒指被頭髮、衣服或角度遮住，不算身分漂移。
- 區分角色要靠骨架與五官，不能只靠髮型、髮色、妝容、眼鏡或衣服。
- 失敗的樣本要保留並記錄原因，不能只交最好的一張。

### 4.3 回報格式（每一批候選）

| 欄位 | 內容 |
|---|---|
| 批次 | 例：L01-CAST-01 |
| 使用的工具、模型與版本 | 實際名稱 |
| prompt 全文與參考圖編號 | 實際使用的內容 |
| 張數 | 生成數、交付數 |
| 實際花費 | 以帳戶實際扣除為準；沒有就寫「未記錄」，不要估算後當成實際值 |
| 審查結果 | 依 4.1 逐項寫「看圖結果」與理由 |
| 失敗樣本 | 保留位置與原因 |
| 待決定事項 | 需要 Penny／客戶決定的事 |

## 5. 誰可以鎖定形象

1. 製作師提出候選人物與做法。
2. Penny 與客戶看圖選定。只有選定之後，那張臉才是該角色的身分基準。
3. 生成完成**不等於**形象核准；製作師或執行者都不能自己宣布「已鎖定」。
4. 選定之後，另外記錄核准版本：哪一張圖、哪個檔案、哪個 commit、誰在哪一天確認。
