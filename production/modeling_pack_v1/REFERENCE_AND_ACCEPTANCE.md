## 2. 參考素材登記表

每一張參考圖都要登記，沒有登記的圖不能放進生成或訓練。

| 欄位 | 說明 |
|---|---|
| 參考編號 | 例：REF-L01-HAIR-OK-01 |
| 角色與類型 | 角色 ID；臉／髮型／體態／服裝／光線／構圖／場景 |
| OK 或 NG | OK＝要往這個方向；NG＝要避開 |
| 原始來源 | 檔案出處或連結；自己拍的寫拍攝人與日期 |
| 權利狀態 | 自拍或自有／授權圖庫（附授權編號）／客戶提供並附授權說明／合成候選（本專案生成）／權利不明 |
| 用途限制 | 授權條款寫的限制，例如只限內部參考、不可商用、不可修改 |
| 可否放進生成輸入 | 可／不可。權利不明的一律不可 |
| 可否用於訓練 | 可／不可。必須授權條款明確允許，且圖中只有本專案的原創人物 |
| 確認人與日期 | 誰確認了權利狀態 |

**臉部參考的特別規則**
- 臉部預設是**原創身分**。真人照片只能當「方向」討論（例如臉型類型、五官比例），不放進生成輸入，也不用來訓練。
- 不用藝人、網紅或任何真實人物的名字描述長相；不要求仿製真人或既有 KOL 的臉。
- 「合成候選」要先由製作師選定（或依其流程交客戶選定），才當身分參考圖；身分參考圖 A／B 由製作師建立與管理。
- 髮型、服裝、光線的參考圖如果有人臉，先裁掉人臉再用，或改用文字描述。不要假設模型會只學髮型而忽略圖中的五官。

### 4.2 判讀規則
- 不使用沒有校準過的數值門檻。臉部相似度之類的自動分數可以當參考，但**自動量測的結果不等於通過**，最後由人看圖判斷，並寫下理由。
- 痣、耳環、刺青、戒指被頭髮、衣服或角度遮住，不算身分漂移。
- 區分角色要靠骨架與五官，不能只靠髮型、髮色、妝容、眼鏡或衣服。
- 失敗的樣本要保留並記錄原因，不能只交最好的一張。
